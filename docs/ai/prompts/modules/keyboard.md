## Feature: keyboard and desktop use

- Shortcuts only where they save real time, shown in tooltips and a "Tastenkürzel" help sheet
  (`?`): `n` new item, `/` focus search, `j`/`k` next/previous, `e` edit, `Esc` close. Ignore
  them while typing in inputs and never override browser shortcuts.
- Multi-select on desktop with checkboxes that appear on hover and `Shift`-click ranges; a
  sticky action bar shows "3 ausgewählt · Verschieben · Löschen".
- Lists and detail side by side from 960 px (`mn-split`), with the selection in the URL.
- Right-click menus are optional extras; every action must also be reachable by button and
  keyboard.
- Drag and drop for reordering and moving between groups, always with a keyboard/menu
  alternative.
