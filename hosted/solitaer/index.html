Regeln

Ziehe vom Stapel Karte für Karte auf den Ablagestapel. Im Tableau legst du Karten absteigend und in abwechselnden Farben aneinander; auf einen leeren Platz darf nur ein König. Die vier Ablagen oben rechts baust du je Farbe vom Ass bis zum König auf. Tippe eine Karte an und dann das Ziel; tippst du dieselbe Karte noch einmal, geht sie von selbst auf ihre Ablage oder an eine passende Stelle. Punkte: Ablagestapel → Tableau +5, Karte auf eine Ablage +10, Karte aufdecken +5, Ablage → Tableau −15. Tastatur: Pfeiltasten wählen, Enter oder Leertaste nimmt auf und legt ab, F schickt auf die Ablage, D zieht eine Karte, Z macht rückgängig.
