    Regeln

    Der Code besteht aus vier Zeichen, gezogen aus sechs; ein Zeichen kann mehrfach vorkommen. Du hast zehn Versuche. Nach jedem Versuch siehst du, wie viele Zeichen am richtigen Platz sitzen („genau“) und wie viele zwar im Code sind, aber an einer anderen Stelle („nah“). Tastatur: 1 bis 6 setzt ein Zeichen, Rücktaste löscht das letzte, Enter ratet.
