# @mininode/gate

Protects every hosted app behind the platform login.

- `src/worker.ts`: default Worker entry for `target: cloudflare` apps. Serves static assets,
  gates page loads, sets security headers (strict CSP, HSTS, …) and serves
  `/_mininode/config.json` for the SDK.
- `src/decide.ts`: runtime-independent decision logic, also used by the NucBox forward-auth:
  - no session → redirect to `mininode.app/login?next=…`
  - expired session → redirect to `mininode.app/auth/refresh?next=…` (central refresh avoids
    refresh-token races between subdomains)
  - no grant → 403 page
- `src/session.ts`: reads the chunked `mn-auth` cookie (`@supabase/ssr` format) and verifies JWTs
  with `jose` against the project's JWKS.

Wrangler configuration for an app (generated by `mininode deploy`):

```jsonc
{
  "main": "../../packages/gate/src/worker.ts",
  "assets": { "directory": "dist", "binding": "ASSETS", "not_found_handling": "single-page-application",
              "run_worker_first": ["/*", "!/assets/*"] },
  "vars": { "APP_SLUG": "rezepte", "APP_NAME": "Rezepte", "PORTAL_URL": "https://mininode.app", … }
}
```
